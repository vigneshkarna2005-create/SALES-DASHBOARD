 SALES-DASHBOARD

Excel Sales Dashboard project for analyzing sales performance and business KPIs.

 📊 Project Overview
This project features a comprehensive, multi-sheet Excel sales dashboard built to track key business metrics, analyze sales trends, evaluate product performance, and examine regional distribution.

 🚀 Key Features & Insights
* **Main Dashboard:** High-level summary featuring monthly sales trends, total sales, net profit, category breakdowns, and top products.
* **Pivot Tables & Reports:** Detailed data breakdowns and summaries organized across dedicated sheets.
* **Regional & Categorical Analysis:** Visual charts displaying performance metrics by region and product category.
* **Raw Dataset:** Clean transaction records containing order details, shipping modes, profit, and quantities.
